How it works

Starting it: double-click TV Remote (the desktop shortcut, or TV Remote.cmd in the Screen Hub\TV Remote folder). It runs quietly in the background until you press Stop TV Remote or restart the PC.

This page runs on this PC only (127.0.0.1) and talks straight to the TVs over the home network, so it is instant but only works at home. Publishing from the console is unchanged.

First use: the TV shows an Allow prompt for “Screen Hub Remote”. Press Allow with the TV remote. If you pressed Deny, allow it under Settings › General › External Device Manager › Device Connection Manager.

Switching on uses Wake-on-LAN. On 2016 Samsungs it works when Samsung Instant On / network standby is on, and is most reliable on a wired connection. The page saves the TV's MAC address the first time it sees the TV switched on.

Show now needs Screen Hub player 1.5.0. It starts Screen Hub if it isn't open, shows the item for the time you pick, then carries on with the playlist. The :00/:30 clock is skipped while it shows.

Saved TVs and connection tokens are in your user folder (.screenhub\tvremote.json), not in the repo.
